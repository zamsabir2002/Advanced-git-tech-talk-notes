## Advance Git Tech Talk Notes

> This repo contains some commands and there breif explanation to carry out a tech talk on advanced git

#### To create slides:

1. Download [MarpSlides for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) 
2. Open `./MarpSlides/advanced-git-tech-talk.md` and Open the **VS Code Command Palette**
3. In the Palette search and select `Marp: Export Slide Deck`
4. You will be prompted to save the slide save and enjoy ☺️.
